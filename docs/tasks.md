# 작업 단계 (macos9-frame-maker)

> 구현 기준: `docs/frame-maker.md`. 사용자가 지정한 Phase만 진행한다.

## Phase P0 — 프로젝트 만들기와 디자인 이식
- [x] `Github/macos9-frame-maker/`에 Vite + React + TypeScript 프로젝트 생성 (이미 있는 AGENTS.md, CLAUDE.md, docs/는 유지), `git init`
- [x] `.gitignore` (node_modules, dist, .DS_Store 등), `.gitattributes` (줄바꿈 LF 고정, 이미지·폰트는 binary)
- [x] 패키지 설치 (명세 1장 표만)
- [x] kkoriworld에서 디자인 파일 복사 (명세 2장). **kkoriworld 원본은 수정하지 않음**
- [x] 복사한 코드에서 API·로그인·게시판 의존성 제거, 타입 오류 0
- [x] 개발용 `/?kit=1` 화면: 기본 컴포넌트와 윈도우 프레임 견본
- 완료 조건: `npx tsc --noEmit` 통과, `npm run build` 성공, `src/`에 fetch·axios·`/api/` 문자열 없음, **사용자 확인**: `npm run dev` 후 `/?kit=1`의 모양이 kkoriworld와 같은지

## Phase P1 — 데스크톱과 윈도우
- [ ] 메뉴 바 (5.1, 홈 아이콘은 아직 동작 없음), 트레이 (5.3)
- [ ] 윈도우 추가·이동·크기 조절·최소화·최대화·닫기·제목 바꾸기 (6장), 비율 좌표 (3.1)
- [ ] 자동 저장·불러오기 (3.2, 이미지 제외)
- 완료 조건: 좌표 변환·자동 저장 테스트, **사용자 확인**: 윈도우 배치 → 새로고침해도 유지 → 브라우저 크기를 바꾸면 비율대로 따라오는지

## Phase P2 — 이미지
- [ ] 이미지 받아들이기 (3.3), 맞춤 계산 (4.1), 편집 화면 (4.2)
- [ ] 윈도우 이미지 (6.3), 배경 (5.2), 사용하지 않는 Blob 정리
- 완료 조건: `fit.ts` 테스트 (가로로 긴·세로로 긴 이미지, zoom, 경계 제한), **사용자 확인**: 이미지 넣기 → 위치·확대 편집 → 윈도우 크기를 바꿔도 꽉 차는지 → 교체·삭제 → 새로고침 후 유지

## Phase P3 — 스티커 모드 (7장)
- 완료 조건: **사용자 확인**: 스티커 올리기·배치·회전·크기 → 모드 종료 → 새로고침 후 유지, GIF 움직임

## Phase P4 — 제어판 (9장)
- [ ] 홈 아이콘 바꾸기 (9장 2번: 바꾸기·위치·크기 편집·기본 아이콘으로, 메뉴 바·탭 파비콘 반영, 즉시 저장)
- 완료 조건: **사용자 확인**: 색 미리보기 → 저장 안 하고 닫으면 원래대로 → 저장 후 새로고침 유지 → 전부 지우기 / 홈 아이콘 바꾸기 → 메뉴 바·탭 파비콘 반영 → 새로고침 후 유지 → 기본 아이콘으로

## Phase P5 — PNG 저장 (8장)
- 완료 조건: **사용자 확인**: Chrome·Safari·Firefox에서 저장 → PNG에 폰트·테마 색·이미지·스티커가 화면과 같게 나오고, 빈 프레임 안내·트레이·제어판은 빠져 있는지
